# Campus Service Desk – Semantic Interface Assignment

A semantic HTML page for submitting and tracking campus service requests.

## How to open
1. Download or clone this folder.
2. Double-click `index.html` (or right-click → Open with → any browser).
3. No server, build step, or internet connection is needed. There are no external files.

## Files
- `index.html` – the complete page (no CSS or JavaScript yet; styling comes in the later CSS topic)
- `README.md` – this file

## Notes
- The page uses no images because its purpose is text, form input, and tabular status data. Images would add no information and would need extra alternative text.
- Validation: checked with the W3C Nu HTML Checker (https://validator.w3.org/#validate_by_upload).
